# xuanji86/homebrew-tap

Homebrew casks for [MacDown2.0](https://github.com/xuanji86/MacDown2.0).

```sh
brew install --cask xuanji86/tap/macdown2
```

MacDown2.0 is ad-hoc signed and not notarized, so it is not in `homebrew/cask`; this cask clears the quarantine flag after install. Updates come through the app itself (Sparkle).
